# Dataset

AlertIQ is built and evaluated against **PaySim**, a synthetic mobile-money
transaction simulator published for fraud-detection research.

## Full dataset (required for real training/evaluation)

1. Download `PS_20174392719_1491204439457_log.csv` from Kaggle:
   [PaySim1 on Kaggle](https://www.kaggle.com/datasets/ealaxi/paysim1)
   (free Kaggle account required).
2. Rename it and place it at:
   ```text
   data/PaySim.csv
   ```
   (create the `data/` folder at the project root — it's git-ignored on
   purpose because the full file is ~470 MB / 6.36M rows).
3. Run the pipeline as described in the root `README.md`.

The full file is not included in this repository — it's too large for
Git, and it's Kaggle's dataset to distribute, not ours.

## `sample_paysim.csv` (included here, for quick testing)

This repository *does* include `sample_paysim.csv` — a small (3,000-row),
**synthetic** dataset generated by `generate_sample.py` that mirrors the
*schema* and rough *statistical shape* of PaySim (transaction type mix,
lognormal amount distribution, fraud concentrated in `CASH_OUT`/`TRANSFER`
at a low base rate).

It exists so that:
- `tests/` can run in under a second with no download required
- `examples/` can demonstrate the real pipeline code end-to-end
- anyone can explore how the code behaves before committing to the ~470 MB
  Kaggle download

**This is not real financial data**, and results produced from it (fraud
recall, ROC-AUC, workload savings, etc.) are **not** representative of the
project's actual reported metrics — those come from the full PaySim
dataset. Re-run `python dataset/generate_sample.py` any time to regenerate
it (it's deterministic given the same seed).

## Schema

| Column | Type | Description |
| --- | --- | --- |
| `step` | int | Time step, 1 hour per step (1-744, i.e. 30 simulated days) |
| `type` | string | `CASH_IN`, `CASH_OUT`, `DEBIT`, `PAYMENT`, `TRANSFER` |
| `amount` | float | Transaction amount |
| `nameOrig` | string | Sender account ID |
| `oldbalanceOrg` | float | Sender balance before the transaction |
| `newbalanceOrig` | float | Sender balance after the transaction |
| `nameDest` | string | Recipient account ID |
| `oldbalanceDest` | float | Recipient balance before the transaction |
| `newbalanceDest` | float | Recipient balance after the transaction |
| `isFraud` | int | Ground-truth label (1 = fraudulent) |
| `isFlaggedFraud` | int | PaySim's own naive over-$200k flag (not used by AlertIQ's rules) |

## Reference

E. A. Lopez-Rojas, A. Elmir, and S. Axelsson, *"PaySim: A financial mobile
money simulator for fraud detection,"* 28th European Modeling and
Simulation Symposium (EMSS), 2016.
